# 星海工作室机位预约｜设计规则 v1.2

更新时间：2026-07-22

## 已锁定视觉

- 延续星海官网深墨黑、暖纸色和金色的品牌视觉。
- 页面只保留日期、时段、座位图、表单和后台操作。
- 两排机器始终为 1/2/3 与 4/5/6 面对面。

## 本轮设计约束

- 延续“杂志编辑”预设和现有深色金棕配色，不引入新颜色或新卡片层级。
- 时间卡改为多选，仍使用现有金色边框和浅金底表达选中。
- 时间区只增加一个小型“全选当天”按钮；不增加说明长文。
- 管理侧操作按范围排列为“当前时段 / 今天全部 / 长期”，危险操作仍使用现有红色按钮。
- 长期维护沿用斜线维护视觉，并在状态文字中明确“长期维护”。
- 状态切换即时完成；静默刷新不显示遮挡式加载层。

## 禁止

- 不增加 Hero、流程说明、营销卡片或装饰插画。
- 不用抽象容量替代具体机器状态。
- 不暴露管理员密码、数据库地址或家长个人信息。
- 不使用弹窗要求管理员逐时段重复确认。
