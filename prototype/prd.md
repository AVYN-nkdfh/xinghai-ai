# 星海工作室机位预约｜PRD v1.1

更新时间：2026-07-22

## 目标

让官网正式预约页可直接使用，并让不同设备共享预约数据。

## 业务规则

- 机器固定为 1–6 号，两排面对面。
- 时段固定为 10:00–13:00、14:00–17:00、18:00–21:00。
- 一个日期、时段和机器只能有一个有效预约。
- 已预约、维护中或关闭时段的机器不能选择。
- 家长无需登录；管理员必须登录。

## 本轮范围

- 连接 Neon PostgreSQL。
- 发布到 `xinghai-ai.com/booking`。
- 修复生产 clean URL 下页面 404 和脚本未加载的问题。
- 验证预约写入、后台读取和取消清理。

## 非目标

- 不改视觉设计和页面结构。
- 不做支付、短信、微信通知、数据导出或多管理员账号。
