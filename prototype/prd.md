# 星海工作室机位预约｜PRD v1.3

更新时间：2026-07-22

## 目标

让官网正式预约页可直接使用，并让不同设备共享预约数据。

## 业务规则

- 机器固定为 1–6 号，两排面对面。
- 时段固定为 10:00–13:00、14:00–17:00、18:00–21:00。
- 一个日期、时段和机器只能有一个有效预约。
- 同一学生可在同一天一次选择 1–3 个时段，所选时段使用同一台机器。
- 多时段预约全部成功后才写入；任何时段冲突则全部失败。
- 已预约、维护中或关闭时段的机器不能选择。
- 多选状态下，每台机器逐时段显示“可选 / 已约 / 维护 / 关闭”；只要一个所选时段不可用，整台机器不可点击，但可用时段仍应明确显示为可选。
- 家长无需登录；管理员必须登录。
- 临时维护分为当前时段和当天全部时段；长期维护对机器全局生效。

## 本轮范围

- 连接 Neon PostgreSQL。
- 发布到 `xinghai-ai.com/booking`。
- 修复生产 clean URL 下页面 404 和脚本未加载的问题。
- 验证预约写入、后台读取和取消清理。
- 家长端支持多选时段和全选当天。
- 管理端支持当前时段、当天全部时段和长期维护。
- 时段切换使用当前日期缓存，不重复请求数据库。
- 多选座位卡显示所选时段的状态明细和具体冲突原因。

## 非目标

- 不做跨日期批量预约，不允许多时段选择不同机器。
- 不改品牌视觉和两排座位结构。
- 不做支付、短信、微信通知、数据导出或多管理员账号。
