# 星海工作室机位预约｜生产契约 v1.0

更新时间：2026-07-22

## 页面 1：官网预约 `/booking/`

### 页面唯一任务

选择日期、时段和具体机器并提交预约。

### 页面结构

1. 正式官网品牌顶栏：返回官网、管理后台。
2. 紧凑标题区：`预约机位` + 一句使用说明。
3. 日期条：未来 7 天。
4. 时段切换：上午、下午、晚间，显示可用机器数。
5. 现场座位图：第一排 1/2/3，中心面对面标识，第二排 4/5/6。
6. 选中摘要和最小表单：姓名、年级、手机号、提交。
7. 成功弹层：日期、时段、机器号、预约编号。

### 机器状态

- 可选：白底、深色边框、显示“可选”。
- 选中：近黑底、白字、显示“已选”。
- 已预约：暖灰底、不可点、显示“已预约”。
- 维护：斜线纹理、不可点、显示“维护中”。

## 页面 2：管理后台 `/booking/#admin`

### 页面唯一任务

按日期和时段管理 1–6 号机器。

### 页面结构

1. 密码登录；通过后显示品牌顶栏和返回家长端入口。
2. 日期条和时段切换。
3. 当前时段开关与统计：可用、预约、维护。
4. 管理座位图：显示机器编号、学生或状态。
5. 选中机器操作区：设为维护、恢复使用、取消预约。
6. 简短预约名单，仅显示当前时段。

## 接受条件

- 家长端首屏不出现营销 Hero、三段说明或流程区。
- 日期、时段、机器三个维度均可操作。
- 两排机器在 1440px 和 390px 下均保持 3+3 面对面结构。
- 后台对机器状态的改动能同步到家长端。
- 不同设备访问同一日期与时段时看到同一份云端数据。
- 同一日期、时段、机器只能有一个有效预约；并发提交时后提交者收到“刚被预约”提示。
- 未登录用户不能读取预约名单或调用维护、关闭、取消接口。
- 正式入口可从 `xinghai-ai.com` 到达，预约页使用当前线上官网视觉。
