# 当前正式官网视觉参考分析 v1.0

更新时间：2026-07-22

## 参考对象

- 正式线上页面：`https://xinghai-ai.com/`，核验版本标记 `2026-07-22-0253`
- Vercel 项目：`xinghai-deploy`，正式域名 `xinghai-ai.com`
- 本轮只提取星海自身的品牌视觉规则，不引用外部竞品。

## 可继承模式

### 品牌识别

- 正式官网使用深墨黑 `#0f0e0c`、暖纸色 `#ece6d8`、金色 `#d3a955`，不是旧原型的米白橙色。
- 标题采用宋体类编辑排版，正文使用系统中文无衬线；整体是克制的深色金棕编辑风格。
- 品牌导航为透明深色层，金色承担主操作和强调，不额外引入科技蓝或高饱和状态色。

### 导航与布局

- 导航固定在页面顶部，品牌在左、文字入口与金色主按钮在右。
- 页面使用宽内容区和较强留白，但预约页第一屏仍直接进入日期、时段与座位选择。
- 预约页继承品牌导航、字体与色彩，不复制官网营销 Hero。

### 组件语言

- 普通按钮和输入组件圆角 10–12px。
- 页面通过边框、留白和轻底色建立层级，不用重装饰。
- 内容优先于插画。预约页第一屏直接放日期和机位，不复制官网营销首屏。

## 对预约系统的转译

1. 家长端沿用官网深墨黑底、暖纸色文字、金色主按钮。
2. 可预约使用金色边框与短状态文字；已占用使用低对比暖灰；维护使用斜线，避免加入绿色模板感。
3. 后台沿用相同品牌壳，但通过边框、表格和状态标签提升操作效率。
4. 官网入口只新增“上机预约”，不改动原有首页叙事和作品内容。

## 不采用的模式

- 不复用官网的营销型大 Hero、漂浮卡片或大面积视觉图，因为预约页的第一任务是看空位。
- 不使用官网旧内容中的蓝色作为预约主色，避免与橙色形成科技模板感。
- 不把官网课程承诺和案例文案带入预约工具。

## 参考结论

正式预约采用“线上官网品牌壳 + 原型已确认的两排选座交互”。生产版以当前线上页面为唯一视觉参考，旧的本地首页不作为上线依据。
