# 星海计划 d-prototype 素材替换说明

把你生成好的图片或视频放在当前目录，并使用下面这些文件名。原型会优先读取同名素材；没有素材时，会显示 CSS 动态占位。

## 通用负面要求

- 不要生成可读文字、logo、水印、版权角色。
- 不要出现真实儿童正脸，除非已经确认肖像授权。
- 画面可以有屏幕、UI、卡片、星图，但屏幕上的内容必须是抽象光块或不可读符号。
- 整体气质：未来感、专业、少年创造力、AI 项目营，不要做成幼儿卡通风。
